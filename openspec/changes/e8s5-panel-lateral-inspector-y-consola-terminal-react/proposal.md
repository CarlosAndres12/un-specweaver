## Why

Entrega la Story 8.5 del Epic 8: Reconstrucción Frontend React + React Flow e Interactividad Bidireccional Software-to-Software.

## What Changes

- Panel Lateral Inspector y Consola Terminal Reactiva.
- Se abre un panel lateral contextual (drawer) mostrando el markdown fuente, requisitos funcionales vinculados, criterios Given/When/Then y estado git.
- Se despliega el terminal drawer con xterm.js, se ejecuta el comando `build` asociado mediante streaming en tiempo real y el nodo en el canvas entra en estado visual animado `building`.
- El nodo transiciona automáticamente a estado verde `completed` en el lienzo con un micro-feedback visual.
